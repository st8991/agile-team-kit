  Its only git mention is "confirm before a force push", which agrees with our
  rules. Upstream's `disable-model-invocation: true` stays, so the reporter reads

  CSV row in each of styles.csv and ux-guidelines.csv, a JSON provenance file,
  catalog counts, tests, one reference line. Upstream changed the script paths in
  SKILL.md to `${CLAUDE_PLUGIN_ROOT}/.claude/skills/...`; we put back our repo-root
  form, as before. Pass.
- **design-taste-frontend re-pin to v2.5.1:** fails. The new SKILL.md frontmatter
  declares a `Stop` hook that runs `node scripts/gate.mjs` for up to 600 seconds on
  every stop, looking for it under plugin roots, the project and `$HOME`. Our rule
  is no skill-declared hooks, and the run would hang unattended agents on a missing
  Chrome. We stay at 12af471 and list v2.5 under Watching.
