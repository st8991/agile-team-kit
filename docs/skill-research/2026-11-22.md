## Security pass

I reviewed every added or re-pinned file as the security-engineer. Scripts were
read, not run.

- **accessibility-engineering**: SKILL.md has no injection, git or permission
  instructions. `scripts/audit-a11y.sh` (233 lines) runs `npx --yes` only for
  `@axe-core/cli@4.13.0` and `pa11y@9.1.1`, writes to a `mktemp -d` dir and removes
  it on exit. It has no curl, eval, sudo or home-dir writes. These npx downloads
  are the one network call, so they are listed under "Tools downloaded at run
  time" in THIRD_PARTY_NOTICES.md, and the note says to report "not run" when the
  network is unavailable. **Pass.**
- **cvss-scoring**: Read-only (`allowed-tools: Read`). The references are metric
  tables and worked examples. The calculator is only linked, never fetched.
  **Pass.**
- **mythical-agent-month**: `totals.py` imports only json and sys and reads the
  file it is given. `calibrate.py` globs Claude Code transcripts in the home
  directory and could expose other projects' session metadata, so **we dropped
  it**, along with the marketing `assets/` and the `evals/` and `examples/`
  folders. The note sends calibration to the team's own board. **Pass with that
  cut.**
- **ui-ux-pro-max re-pin**: The diff adds a token exporter, data rows and tests.
  The only new URL is the DTCG `$schema` string written into output; nothing is
  fetched. Token files are written only with `--persist`, which our note forbids.
  The SKILL.md frontmatter changed only the counts in `description`, with no
  hooks. **Pass.**
- **trailofbits and addyosmani re-pins**: The vendored files are identical except
  the shared accessibility checklist (text only). **Pass.**
