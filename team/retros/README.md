# Retrospectives

Per sprint:
- `sprint-NN-notes.md` — captured during the sprint: every agent's `Retro note`,
  the scrum master's process notes, and the owner's feedback. Starts with any
  open action items from the previous retro.
- `sprint-NN.md` — the day-5 retro: data, every role's keep/stop/try, every
  note acknowledged with a disposition, and up to 3 action items.

Owners can add notes any time: write them in team/INBOX.md starting with "Retro:".
