# Inbox — owner → team

Write requests, answers to the team's questions, and approvals here, newest at the
bottom. The product manager processes new items at the start of every run and
marks them `[processed → S-0xx]`. You can edit this file straight on GitHub.
Start a line with "Retro:" to add a note to the current sprint's retrospective.

Examples:
- 2026-11-02 · Add a high-score table that persists between sessions.
- 2026-11-03 · Re: ADR-002 — approved, go with SQLite.
- 2026-11-03 · Priority: fix the mobile layout before anything new.
- 2026-11-04 · Retro: the daily report is too long; keep it to one screen.

---

- YYYY-MM-DD · Kickoff. Turn the Roadmap in CLAUDE.md into stories; Sprint 1
  should be the foundation (root build/lint/test commands and CI).
